# SimulinkAgenticToolkit-WebPage

GitHub Pages 전용 저장소입니다. [SATK_Offline_Installation](https://github.com/jongils/SATK_Offline_Installation)의
GitHub Actions 워크플로우가 매 빌드마다 `Introduction.html`과 `SimulinkAgenticToolkit_News.html`을 이 저장소에
자동으로 push합니다. 사람이 직접 수정하지 않습니다 — 다음 자동 빌드가 덮어씁니다.

GitHub Release의 asset은 브라우저에서 다운로드만 되고 바로 열리지 않는 문제 때문에, 브라우저에서 바로 열람 가능하도록
이 별도의 public 저장소 + GitHub Pages로 배포합니다. 원본 소스(SATK_Offline_Installation)는 private으로 유지됩니다.
