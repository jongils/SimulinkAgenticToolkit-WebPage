simulink-agentic-toolkit (2026.08.19)

저장소 바로가기: https://github.com/matlab/simulink-agentic-toolkit

# SATK v2026.08.19

## Quick Start

### Fresh Install

1. Download `agenticToolkitInstaller.mltbx` from the release assets
2. In MATLAB, double-click the `.mltbx` to install, then run:

```
>> setupAgenticToolkit("install")
```

3. Each MATLAB session, initialize the toolkit:

```
>> addpath("~/.matlab/agentic-toolkits/simulink")
>> satk_initialize
```

### Update Existing Installation

1. Download `agenticToolkitInstaller.mltbx` from the release assets
2. Double-click the `.mltbx` to update installer files, then run:

```
>> setupAgenticToolkit("update")
```

3. Each session, initialize with the same `addpath` and `satk_initialize` commands as above.

## What's New

- **`simulink-control-motors` skill** — New skill that guides agents through building Motor Control Blockset models, with proven architecture patterns and ready-made configurations for 16 motor drive topologies.

## Improved Skills and Tools

- **`checking-model-compliance` skill** — Now supports checking models against Simulink Code Inspector (SLCI) in addition to the existing compliance standards.

- **Clearer simulation error diagnostics** — When a simulation fails, `model_read_diagnostics` now reports the underlying cause of the error, including the specific block path and error details that were previously hidden behind a generic message.

## Bug Fixes

- **Small models could be misread as empty** — Agents no longer misinterpret small, simple models as empty when asked to explain them.

- **Rewiring a masked Simscape Power Systems port could connect the wrong endpoint** — `model_edit` now connects to the intended physical port when rewiring masked Specialized Power Systems blocks. ([#63](https://github.com/matlab/simulink-agentic-toolkit/issues/63))

- **A failed connect could silently delete an existing connection** — When connecting to an already-connected input port fails, `model_edit` now preserves the original connection instead of removing it. ([#62](https://github.com/matlab/simulink-agentic-toolkit/issues/62))

- **`Trigonometric Function` added by name computed an approximated sine** — Adding a `Trigonometric Function` block by its Simulink Library Browser name now produces the exact sine instead of a CORDIC approximation, avoiding silent output differences. ([#61](https://github.com/matlab/simulink-agentic-toolkit/issues/61))

matlab-agentic-toolkit (2026.08.13)

## What's New (2026.08.13)

### New Skills in Existing Skill Groups

- **Image Processing and Computer Vision** — `matlab-analyze-spectral-images` for reading, processing, analyzing, labeling, and classifying hyperspectral and multispectral images.

### Improved Skills

- `matlab-analyze-data` — Expanded `convertvars` documentation covering function-handle selectors and in-place transforms.
- `matlab-build-industrial-hmi` — Added hand-off to `matlab-build-app` for App Designer serialization with `.mlapp` output, and a programmatic fallback when unavailable.
- `matlab-deploy-ai-model` — Added LiteRT&trade; codegen support (loadLiteRTModel) for both MATLAB&reg; and Simulink&reg; workflows.
- `matlab-deploy-embedded-code` — Refined ARM&reg; Cortex-A SIMD/CRL guidance and added reference for Simulink Coder properties.
- `matlab-design-radar-waveform` — Added spread-spectrum and phase-coded waveform support (M-sequence, PN code, dual-function radar-communication waveforms) and spectral notching reference.
- `matlab-generate-code` — Added host-target SIMD configuration (InstructionSetExtensions, SIMDAcceleration, OptimizeReductions) and OpenMP guidance for lib/dll/exe and MEX targets.
- `matlab-install-products` — Enhanced Windows&reg; agent support with stricter file-creation protocol for PowerShell-based workflows.
