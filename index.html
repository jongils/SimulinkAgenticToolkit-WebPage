MATLAB · Simulink Agentic Toolkit 소식

빌드 날짜: 2026-08-20

이번 빌드 한눈에 보기

  • Simulink — 16가지 모터 구동 토폴로지를 지원하는 신규 simulink-control-motors 스킬 추가, 시뮬레이션 오류 진단 개선, 포트 재배선·연결 관련 버그 3건 수정.
  • MATLAB Agentic Toolkit — 초분광/다중분광 이미지 분석 신규 스킬 추가, 7개 기존 스킬 문서·기능 보강, 스킬 22개 이름 변경 및 3개 스킬 통합(호환성 유의).
  • MATLAB MCP Server — 에이전트 연결 시 MATLAB 명령 창에 알림 메시지 표시.

matlab-mcp-server v0.12.0

새로운 기능

  • AI 에이전트가 MATLAB MCP Server를 통해 연결되면, MATLAB 명령 창에 연결 사실을 알리는 메시지가 표시됩니다. 이제 사용자는 에이전트가 언제 MATLAB 세션에 접속했는지 별도 확인 없이 바로 알 수 있습니다.

이 외의 변경사항은 없습니다.

simulink-agentic-toolkit 2026.08.19

새로운 기능

  • simulink-control-motors 스킬 신설 — 에이전트가 Motor Control Blockset 모델을 구축할 때 검증된 아키텍처 패턴과 16가지 모터 구동 토폴로지에 대한 사전 구성 설정을 제공하여 안내합니다.

기존 스킬·도구 개선

  • checking-model-compliance 스킬 — 기존 컴플라이언스 표준 검사에 더해, 이제 Simulink Code Inspector(SLCI) 기준의 모델 검사도 지원합니다.
  • 시뮬레이션 오류 진단 개선 — 시뮬레이션 실패 시 model_read_diagnostics가 이전에는 일반적인 메시지로만 표시되던 오류의 근본 원인을, 구체적인 블록 경로 및 세부 오류 정보와 함께 알려줍니다.

버그 수정

  • 소형 모델을 빈 모델로 오인하는 문제 — 에이전트가 작고 단순한 모델을 설명 요청 시 더 이상 빈 모델로 잘못 해석하지 않습니다.
  • 마스킹된 Simscape Power Systems 포트 재배선 시 잘못된 연결 문제 — model_edit이 마스킹된 Specialized Power Systems 블록을 재배선할 때, 이제 의도한 물리적 포트에 정확히 연결됩니다. (#63)
  • 연결 실패 시 기존 연결이 삭제되던 문제 — 이미 연결된 입력 포트에 연결을 시도했다가 실패하는 경우, model_edit이 기존 연결을 삭제하지 않고 그대로 보존합니다. (#62)
  • Trigonometric Function 블록 이름 추가 시 근사 사인값 계산 문제 — Simulink 라이브러리 브라우저 이름으로 Trigonometric Function 블록을 추가할 때, 이제 CORDIC 근사값이 아닌 정확한 사인값을 계산하여 결과가 조용히 달라지는 문제를 방지합니다. (#61)

matlab-agentic-toolkit 2026.08.13

기존 스킬 그룹 내 신규 스킬

  • 이미지 처리 및 컴퓨터 비전 — 초분광(hyperspectral) 및 다중분광(multispectral) 이미지를 읽고, 처리하고, 분석하고, 레이블링하고, 분류하기 위한 matlab-analyze-spectral-images 스킬이 추가되었습니다.

기존 스킬 개선

  • matlab-analyze-data — 함수 핸들 선택자 및 in-place 변환을 다루는 convertvars 관련 문서가 확장되었습니다.
  • matlab-build-industrial-hmi — App Designer의 .mlapp 직렬화를 위한 matlab-build-app 연계 기능과, 이를 사용할 수 없는 경우를 위한 프로그래밍 방식의 대체 경로가 추가되었습니다.
  • matlab-deploy-ai-model — MATLAB 및 Simulink 워크플로우 모두에 대해 LiteRT™ 코드 생성 지원(loadLiteRTModel)이 추가되었습니다.
  • matlab-deploy-embedded-code — ARM® Cortex-A SIMD/CRL 관련 안내가 개선되었고 Simulink Coder 속성에 대한 참고 자료가 추가되었습니다.
  • matlab-design-radar-waveform — 스프레드 스펙트럼 및 위상 부호화 파형 지원(M-시퀀스, PN 코드, 이중 기능 레이더-통신 파형)과 스펙트럼 노칭 참고 자료가 추가되었습니다.
  • matlab-generate-code — 호스트-타깃 SIMD 설정(InstructionSetExtensions, SIMDAcceleration, OptimizeReductions) 및 lib/dll/exe와 MEX 타깃을 위한 OpenMP 안내가 추가되었습니다.
  • matlab-install-products — PowerShell 기반 워크플로우를 위한 파일 생성 프로토콜이 강화되어 Windows® 에이전트 지원이 개선되었습니다.

호환성 관련 유의사항

  • 스킬 22개 이름 변경 — 툴킷 내 다른 스킬과의 명확성 및 일관성을 위해 22개 스킬의 이름이 변경되었습니다. 이전 버전의 스킬을 설치한 경우, 인스톨러를 다시 실행하여 새 버전으로 전환해야 합니다. 에이전트 지침 등에서 이전 스킬 이름을 수동으로 참조하고 있다면 함께 업데이트해야 합니다. (예: matlab-debugging → matlab-debug-code, matlab-read-doc → matlab-read-documentation, matlab-testing → matlab-write-test 등 총 22건)
  • 스킬 3종 통합 — 여러 개별 스킬이 통합 스킬로 대체되었습니다. 개별 스킬을 설치한 경우 인스톨러를 다시 실행하여 통합 버전으로 전환해야 합니다.
    • matlab-analyze-dependencies, matlab-assess-toolbox, matlab-build-toolbox, matlab-create-buildfile, matlab-create-project, matlab-define-toolbox-api, matlab-document-toolbox, matlab-exclude-files, matlab-publish-toolbox → matlab-package-toolbox
    • matlab-connect-databricks-jdbc, matlab-connect-databricks-spark → matlab-connect-databricks
    • matlab-map-database-objects, matlab-read-database, matlab-write-database → matlab-use-database
