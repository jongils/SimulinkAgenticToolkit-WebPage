새로운 기능

1건

simscape-write-ssc 스킬 추가

커스텀 컴포넌트의 동작, 파라미터화, 인터페이스 정의를 위한 Simscape Language 소스 파일(.ssc)을 작성, 편집, 검증하도록 안내하는 새로운 스킬입니다. 이 스킬을 사용하려면 Simscape가 필요합니다.

스킬 및 도구 개선

1건

커스텀 라이브러리 설정을 프로젝트 디렉터리에 저장 가능

satk.Configuration의 setCustomLibraries, setLibrary 메서드가 선택적 Location 인자를 지원합니다. 기본 사용자 전용 위치 대신 커밋 가능한 프로젝트 디렉터리에 설정을 기록할 수 있으며, 라이브러리 경로는 해당 위치 기준 상대 경로로 저장되어 소스 관리에 포함시켜 팀과 공유할 수 있습니다.

버그 수정

5건

Extract Bits 블록이 잘못 생성되던 문제 수정

"Extract Bits" 블록을 추가하면 다른 동작을 수행하는 "Float Extract Bits" 블록이 대신 생성되던 문제를 수정했습니다. (#73)

Truth Table 블록이 잘못 생성되던 문제 수정

"Truth Table"을 추가하면 "Combinatorial Logic" 블록이 대신 생성되던 문제를 수정했습니다. (#74)

Relational Operator 반전 문제 수정

Relational Operator를 >=로 설정하면 <=로 반전되던 문제를 수정했습니다. (#77)

.mdl 전용 커스텀 라이브러리 폴더 인식

setCustomLibraries에 레거시 .mdl 파일만 있는 디렉터리를 지정하면 블록이 0개로 등록되던 문제를 수정했습니다. 이제 .slx와 .mdl 파일이 모두 인식됩니다. (#72)

update 명령의 마일스톤 버전 비교 오류 수정

SATK-2026.09.a에서 SATK-2026.09.b로 업데이트할 때 두 버전을 동일하게 취급해 "Everything is up to date"로 잘못 보고하던 문제를 수정했습니다. (#78, #79)

추가 버그 수정

2건

커스텀 라이브러리 정책 준수 오류 수정

.satk/ 폴더 없이 플랫 설정 파일만 사용하는 프로젝트에서 커스텀 라이브러리 정책이 지정되어 있어도 model_edit가 내장 블록을 추가하던 문제를 수정했습니다. (#82)

자동 레이아웃 개선

이미 배치된 다이어그램에 블록을 추가할 때 기존 배치가 흐트러지는 현상과 블록/신호 이름 겹침 현상을 줄였습니다. 피드백 루프, 병렬 분기, 물리적 연결이 있는 모델에서 라인 라우팅도 더 깔끔해졌습니다.

MATLAB Agentic Toolkit

matlab-agentic-toolkit MATK-2026.09.a

새로운 스킬 (기존 스킬 그룹 내)

7건

matlab-run-tests (MATLAB Core)

MATLAB 테스트 스위트 실행, 코드 커버리지 수집, CI/CD 파이프라인 구성을 위한 스킬입니다.

matlab-write-tests (MATLAB Core)

클래스 기반 테스트 프레임워크를 사용해 MATLAB 단위 테스트를 생성하고 구조화하는 스킬입니다.

matlab-analyze-reliability (AI and Statistics)

신뢰성 분석을 위한 수명 분포 및 가속 수명 모델을 피팅하는 스킬입니다.

matlab-optimize-portfolio (Computational Finance)

평균-분산 포트폴리오 최적화 문제를 구성하고 해결하는 스킬입니다.

matlab-price-instrument (Computational Finance)

Monte Carlo, FFT, 이자율 트리를 이용해 금융 상품 가격을 산정하는 스킬입니다.

matlab-design-radar (Radar)

Radar Designer 앱에서 레이더 시스템을 설계, 구성, 분석하는 스킬입니다.

스킬 개선

3건

matlab-access-datafeed

datastreamws 인터페이스를 통한 LSEG Datastream 과거 데이터 조회 지원이 추가되었습니다.

matlab-analyze-data

확장된 참조 파일과 함께 라우터 스타일 구조로 재구성되어 에이전트의 참조 파일 읽기 성공률이 높아졌고, 관련 스킬 간 상호 참조가 추가되었습니다.

matlab-build-app

백그라운드 작업 및 타이머 패턴, MVVM(Model-View-ViewModel) 백그라운드 작업 가이드, 독립형 HTML 차트 및 브리지 자산 템플릿이 추가되었습니다.

호환성 관련 유의사항

1건

matlab-write-test 스킬 분리

matlab-write-test가 matlab-write-tests(단위 테스트 작성)와 matlab-run-tests(테스트 스위트 실행 및 커버리지 수집) 두 개로 분리되었습니다. 기존에 matlab-write-test를 설치했다면 설치 프로그램을 다시 실행하여 새 스킬로 전환해야 합니다.

기타 변경사항

1건

릴리스 태그 형식 변경

릴리스 태그가 더 이상 날짜 기반 YYYY.MM.DD 형식을 사용하지 않습니다. 이제 MATK-YYYY.MM.x 형식을 따릅니다 (예: MATK-2026.09.a).

Polyspace Agentic Toolkit

polyspace-agentic-toolkit v2026.09.08

새로운 스킬 그룹 4개새로운 스킬 8개호환성 관련 유의사항 (스킬 재편)설치 프로그램 개선

새로운 스킬 그룹

4건

Polyspace Core (polyspace-core)

항상 설치되는 그룹으로, Polyspace 설치 루트를 확인하고 빌드 옵션을 구성하며 모든 워크플로우가 공유하는 문서 진입점을 제공합니다.

Polyspace Static Core (polyspace-static-core)

Polyspace as You Code, Bug Finder, Code Prover 중 하나라도 설치되어 있으면 함께 설치되는 공용 정적분석 워크플로우입니다. 발견 사항 검토/수정/정당화, 체커 구성, 체커·옵션 문서 조회를 제공합니다.

Polyspace Bug Finder (polyspace-bug-finder)

여러 파일 또는 전체 컴포넌트에 대한 결함 및 코딩 표준 준수 여부를 분석합니다.

Polyspace Code Prover (polyspace-code-prover)

런타임 오류가 없음을 증명하고, red/orange/green/gray 체크를 검토하며, 증명되지 않은(orange) 체크를 분류합니다.

기존 스킬 그룹 내 새로운 스킬

8건

run-polyspace-bug-finder-analysis

여러 파일 또는 전체 컴포넌트에 대해 Bug Finder를 실행합니다.

run-polyspace-code-prover-analysis

C/C++ 코드에 대해 Code Prover를 실행합니다.

review-polyspace-code-prover-results

체크 결과를 읽고 우선순위를 매깁니다.

triage-orange-checks

증명되지 않은(orange) 체크에 대해 어떤 조치를 취할지 결정합니다.

resolve-polyspace-root

명령줄 폴백을 위한 설치 루트를 찾습니다.

polyspace-review-findings / polyspace-justify-in-database

발견 사항을 읽고 설명하고 우선순위를 매기는 전용 스킬과, 결과 데이터베이스에 검토 상태와 근거를 기록해 재실행 시에도 유지하는 스킬입니다.

run-polyspace-test-xunit-tests

PSTUnit 테스트를 빌드 및 실행하고, 선택적으로 코드 커버리지를 계산합니다. Make/CMake 기반 빌드 시스템이 있으면 테스트를 통합한 빌드 파일 사본을 생성하며, 테스트 등록 누락 같은 일반적인 문제를 처리합니다.

개선된 스킬

2건

run-polyspace-as-you-code-analysis

공유되는 검토/수정/정당화/체커/문서 스킬이 polyspace-static-core로 이동함에 따라, 현재 편집 중인 파일 단위 분석에 집중하도록 개선되었습니다.

C 및 C++ API 레퍼런스를 포함하여 PSTUnit 테스트 작성 가이드가 확장되었습니다.

Agentic Toolkit Installer 개선

3건

선택적 설치

설치 시 사용자가 확인한 세트에 따라 실제로 설치된 Polyspace 제품을 감지하여 해당하는 스킬 그룹만 설치합니다. polyspace-core는 항상 설치되고, 정적분석 제품이 하나라도 있으면 polyspace-static-core가 함께 설치됩니다. polyspace-test는 polyspace-static-core를 필요로 하지 않습니다. 로드되는 스킬 수가 줄어들어 에이전트가 올바른 스킬을 더 안정적으로 트리거합니다.

타겟 스킬 등록

scripts/install-global-skills.sh가 선택적으로 스킬 그룹 이름 목록을 인자로 받도록 개선되어, 심볼릭 링크 기반 에이전트가 선택된 그룹만 등록할 수 있습니다 (인자가 없으면 이전과 같이 전체 설치).

Claude Code용 자동 종속성

각 제품 플러그인(polyspace-as-you-code, polyspace-bug-finder, polyspace-code-prover)이 polyspace-static-core를 종속성으로 선언하므로, 제품 플러그인을 설치하면 공유 정적분석 스킬이 자동으로 함께 설치됩니다.

기타 변경사항

2건

확장된 MCP 도구 범위

MCP Tools 문서가 Bug Finder/Code Prover 분석(run_polyspace_bug_finder, run_polyspace_code_prover), Code Prover 전용 조사 도구(get_code_prover_assumptions, get_concurrency_model, get_orange_sources, get_static_ranges), get_dead_code_blocks를 포함한 추가 결과 탐색 도구를 다루도록 확장되었습니다.
