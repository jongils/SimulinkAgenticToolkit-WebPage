에이전트 연결 시 MATLAB에 알림 메시지 표시

AI 에이전트가 MATLAB MCP Server를 통해 연결되면 MATLAB 커맨드 윈도우에 안내 메시지가 표시됩니다. 사용자가 에이전트의 연결 여부를 별도 확인 없이 바로 알 수 있게 되었습니다.

새로운 기능

6건

simulink-explain-missing-coverage 스킬 추가

이미 보유한 Simulink Coverage 결과에서 커버리지 목표가 누락된 원인을 설명하는 신규 스킬입니다. 도달 불가능한(dead) 로직과 도달은 가능하지만 테스트되지 않은 결과를 구분하고, 테스트 추가·필터·설계 수정 중 적절한 조치를 추천합니다.

simulink-generate-embedded-code 스킬 추가

Simulink 모델과 참조 모델 계층 전반에 Embedded Coder 프로덕션 코드 생성을 위한 타깃, 하드웨어, 최적화, MISRA 준수 설정을 구성하는 신규 스킬입니다.

simulink-customize-a2l 스킬 추가

Embedded Coder로 Simulink 모델에서 생성한 A2L(ASAP2) 캘리브레이션 파일을 커스터마이즈하는 신규 스킬입니다.

simulink-streaming-dsp 스킬 추가

프레임 기반 스트리밍 DSP 모델을 구축하는 에이전트를 위해 적절한 블록 선택과 프레임 구성을 안내하는 신규 스킬입니다.

finding-simulink-examples 스킬 추가

MathWorks가 제공하는 예제 모델 카탈로그를 검색하여, 일치하는 예제를 바로 열 수 있는 명령을 반환하는 신규 스킬입니다.

사전 빌드된 툴박스 블록 지원

Aerospace Blockset, Simscape 등 설치된 MathWorks 툴박스를 활성화하여, 에이전트가 런타임에 라이브러리를 스캔하지 않고도 필요할 때 해당 툴박스의 블록으로 모델을 구성할 수 있습니다.

스킬 및 도구 개선

1건

simulink-curating-library-kg 스킬 이름 변경 및 개선

라이브러리 큐레이션 스킬이 기존 curating-library-kg에서 이름이 변경되고, 더 명확한 가드레일과 커스텀 라이브러리를 위한 향상된 블록 선택 가이드를 갖추도록 개선되었습니다. 프롬프트, 스크립트, 에이전트 설정 등에서 이 스킬을 이름으로 참조하고 있다면 새 이름으로 업데이트해야 합니다.

버그 수정

3건

커스텀 라이브러리 블록이 잘못 차단되는 문제

블록 이름이 block-policy 목록에 있는 블록과 접두어를 공유하는 경우, model_edit이 더 이상 해당 블록을 잘못 거부하지 않습니다. (#66)

깊이 중첩된 컴포넌트 테스트가 시작 전에 실패하던 문제

테스트 대상 컴포넌트가 모델 계층 구조 깊숙이 위치한 경우에도 model_test가 이름 지정 오류로 실패하지 않고 정상적으로 실행됩니다.

프로젝트 라이브러리 구성의 이식성 문제

프로젝트에 저장된 커스텀 라이브러리 구성이 이제 상대 경로를 사용하여, 프로젝트를 다른 머신으로 옮겨도 계속 정상 동작합니다.

기존 스킬 그룹 내 신규 스킬

3건

AI and Statistics — matlab-engineer-tabular-features

단일 응답(single-response) 테이블형 분류·회귀 문제를 위한 최적의 특징(feature)을 설계하고 선택하는 신규 스킬입니다.

Math and Optimization — matlab-use-symbolic-math

해석적 해, 방정식 풀이, 미적분, 변환, 코드 생성을 위해 Symbolic Math Toolbox™를 사용하는 올바른 MATLAB® 코드를 생성하는 신규 스킬입니다.

Signal Processing — matlab-analyze-spectrum

비모수(nonparametric) 및 모수(parametric) 추정기를 사용해 신호 스펙트럼을 분석하는 신규 스킬입니다.

개선된 스킬

10건

matlab-add-awgn

OFDM 잡음 주입 패턴과 부분 점유(partially-occupied) 그리드를 위한 SNR 변환 규칙이 추가되었습니다.

matlab-classify-tabular-data

헬퍼 스크립트와 모델 카탈로그가 명확성을 위해 재구성되었고, 계층화(stratified) 서브샘플링과 개선된 내보내기(export) 워크플로 스크립트가 추가되었습니다.

matlab-discover-hardware

명시적인 스킬 경계(skill-boundary) 가이드와 장치별(device-specific) 동적 스킬 라우팅이 추가되었습니다.

matlab-migrate-settings

설치 자동 감지 참조, DLL 경로 추출 가이드가 추가되고 스킬 지침이 정교화되었습니다.

matlab-modernize-code

오디오/비디오, 통신, 제어 시스템, 핵심 함수, 딥러닝, 이미지 처리, 매핑, 최적화, 신호 처리, 통계/ML 등 도메인별 현대화(modernization) 가이드가 추가되었습니다.

matlab-use-opcua-client

OPC UA 네임스페이스를 탐색하고 검사하기 위한 서버 노드 탐색 및 노드 함수 참조가 추가되었습니다.

matlab-validate-function-arguments

@islogical 마이그레이션 가이드를 개선하여 허용 입력 범위가 의도치 않게 넓어지는 것을 방지합니다.

simbiology-build-model

위치 지정 스크립트를 갖춘 다이어그램 레이아웃 엔진, PK 라이브러리 가이드, 앱 라이프사이클 관리, API 치트시트 참조가 추가되었습니다.

simbiology-fit-model

NCA 분석 가이드가 추가되고 피팅(fitting) 워크플로 지침이 확장되었습니다.

simbiology-simulate-model

민감도 분석(sensitivity analysis) 및 확률적(stochastic) 시뮬레이션 가이드가 추가되었습니다.
