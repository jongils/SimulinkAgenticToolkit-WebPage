simulink-agentic-toolkit 2026.08.12

새로운 기능

  • simulink-use-c-function-block 스킬 추가 — 에이전트가 사용자 정의 C/C++ 코드를 Simulink 모델에 통합할 때, 레거시 S-Function 방식 대신 C Function 블록을 구성하도록 안내하는 신규 스킬입니다.

스킬 및 도구 개선

  • simulating-simulink-models 스킬 정교화 — 파라미터 오버라이드, 배치 실행, 사용자 지정 입력 등 구체적인 시뮬레이션 설정을 요청할 때만 활성화되도록 개선되어, 다른 스킬이 처리해야 할 일반적인 모델링 요청에서는 더 이상 불필요하게 트리거되지 않습니다.
  • author-modeladvisor-checks 스킬 확장 — 포맷 템플릿 검사(format-template checks), 구성 파라미터 검사(configuration-parameter checks), 컴파일 후 컨텍스트 검사(post-compile context checks) 등 더 많은 Model Advisor 검사 유형 작성을 지원하며, 레거시 검사를 최신 상세 스타일로 변환하는 기능도 추가되었습니다.

버그 수정

  • model_edit의 Sqrt/Product 블록 오생성 문제 — Sqrt 블록을 요청하면 더 이상 역제곱근(1/sqrt(x)) 블록이 생성되지 않고, Product 블록을 요청하면 더 이상 나눗셈(divide) 블록이 생성되지 않습니다. (Issue #58, #57)
  • Integrator, Second-Order 블록 오인식 문제 — Simulink Library Browser 명칭으로 Integrator, Second-Order 블록을 추가하면 일반 Integrator가 아닌 실제 2차 적분기(Second-Order Integrator) 블록이 생성되도록 수정했습니다. (Issue #55)
  • setupAgenticToolkit("update") 다운로드 실패 문제 — 다운로드 타임아웃이 짧아 느린 네트워크 환경에서 업데이트가 실패하던 문제를 해결했습니다. (Issue #59)
  • 일반 모델이 포함된 디렉터리의 커스텀 라이브러리 등록 실패 — 라이브러리가 아닌 일반 모델 파일이 함께 있는 디렉터리를 등록할 때 더 이상 실패하지 않으며, 라이브러리가 아닌 파일은 자동으로 건너뜁니다.
  • model_edit에서 DateTime 블록 사용 불가 문제 — 이제 에이전트가 모델 작성 시 Simulink DateTime 블록 계열을 추가할 수 있습니다.
  • Simscape 물리 포트 레이블 불일치 — 동일 포트에 여러 연결이 있는 Simscape 서브시스템에서, 모델 개요와 읽기 결과의 포트 레이블이 일관되게 표시되도록 수정했습니다.
  • 자동 레이아웃 안정성 개선 — 서로 다른 다이어그램에 대한 연속적인 레이아웃 요청이 더 이상 오류를 일으키지 않으며, 결과를 사용할 수 없을 때 멈추지 않고 빠르게 실패하도록 개선했습니다.

matlab-agentic-toolkit 2026.08.13

기존 스킬 그룹 내 신규 스킬

  • 이미지 처리 및 컴퓨터 비전 — 초분광(hyperspectral) 및 다중분광(multispectral) 이미지를 읽고, 처리하고, 분석하고, 라벨링하고, 분류하기 위한 matlab-analyze-spectral-images 스킬이 추가되었습니다.

개선된 스킬

  • matlab-analyze-data — 함수 핸들 선택자(function-handle selector) 및 in-place 변환을 다루는 convertvars 문서가 확장되었습니다.
  • matlab-build-industrial-hmi — .mlapp 출력을 위한 App Designer 직렬화 시 matlab-build-app으로의 핸드오프가 추가되었고, 사용할 수 없는 경우를 위한 프로그래밍 방식 대체 경로도 추가되었습니다.
  • matlab-deploy-ai-model — MATLAB 및 Simulink 워크플로 모두에서 LiteRT™ 코드 생성 지원(loadLiteRTModel)이 추가되었습니다.
  • matlab-deploy-embedded-code — ARM® Cortex-A SIMD/CRL 가이드가 개선되었고, Simulink Coder 속성에 대한 참조가 추가되었습니다.
  • matlab-design-radar-waveform — 스프레드 스펙트럼 및 위상 코딩 파형(M-sequence, PN 코드, 듀얼 기능 레이더-통신 파형) 지원과 스펙트럼 노칭(notching) 참조가 추가되었습니다.
  • matlab-generate-code — 호스트-타깃 SIMD 구성(InstructionSetExtensions, SIMDAcceleration, OptimizeReductions)과 lib/dll/exe 및 MEX 타깃을 위한 OpenMP 가이드가 추가되었습니다.
  • matlab-install-products — PowerShell 기반 워크플로에 대한 엄격한 파일 생성 프로토콜을 적용하여 Windows® 에이전트 지원이 강화되었습니다.
