v0.12.0

새로운 기능

  • MATLAB MCP Server를 통해 에이전트가 연결되면 MATLAB 커맨드 창에 연결 알림 메시지를 표시하는 기능이 추가되었습니다. 이제 사용자는 별도 확인 없이도 에이전트가 현재 MATLAB 세션에 연결되었는지 바로 알 수 있습니다.

simulink-agentic-toolkit

2026.08.19

새로운 기능

  • simulink-control-motors 스킬 추가 — Motor Control Blockset 모델을 구축하는 과정을 안내하는 신규 스킬입니다. 검증된 아키텍처 패턴과 16가지 모터 드라이브 토폴로지에 대한 사전 구성 설정을 함께 제공합니다.

기존 스킬 및 도구 개선

  • checking-model-compliance 스킬 — 기존 컴플라이언스 표준 검사에 더해 Simulink Code Inspector(SLCI) 기준 검사를 지원하도록 확장되었습니다.
  • 시뮬레이션 오류 진단 개선 — 시뮬레이션이 실패했을 때 model_read_diagnostics가 이전에는 일반적인 오류 메시지 뒤에 숨겨져 있던 근본 원인(구체적인 블록 경로 및 오류 상세 정보)을 함께 보고하도록 개선되었습니다.

버그 수정

  • 작은 모델이 빈 모델로 잘못 인식되는 문제 — 에이전트가 모델을 설명하도록 요청받았을 때, 작고 단순한 모델을 더 이상 빈 모델로 오인하지 않습니다.
  • 마스킹된 Simscape Power Systems 포트 재배선 오류 — 마스킹된 Specialized Power Systems 블록의 배선을 변경할 때 model_edit이 이제 의도한 물리적 포트에 정확히 연결됩니다. (이슈 #63)
  • 연결 실패 시 기존 연결이 삭제되던 문제 — 이미 연결된 입력 포트에 다시 연결을 시도하다가 실패하는 경우, model_edit이 기존 연결을 제거하지 않고 그대로 보존합니다. (이슈 #62)
  • Trigonometric Function 블록의 근사 사인 계산 문제 — Simulink 라이브러리 브라우저 이름으로 Trigonometric Function 블록을 추가하면 이제 CORDIC 근사값이 아닌 정확한 사인 값을 계산하여, 눈에 띄지 않게 출력이 달라지는 문제를 방지합니다. (이슈 #61)

matlab-agentic-toolkit

2026.08.13

새로운 스킬

  • Image Processing and Computer Vision 그룹 — matlab-analyze-spectral-images 스킬이 추가되었습니다. 초분광(hyperspectral) 및 다중분광(multispectral) 이미지를 읽고, 처리하고, 분석하고, 레이블링하고, 분류하는 작업을 지원합니다.

기존 스킬 개선

  • matlab-analyze-data — 함수 핸들 기반 선택자와 in-place 변환을 포함하도록 convertvars 관련 문서가 확장되었습니다.
  • matlab-build-industrial-hmi — App Designer 직렬화(.mlapp 출력)를 위한 matlab-build-app 연계 기능과, 이를 사용할 수 없을 때의 프로그래밍 방식 대체 경로가 추가되었습니다.
  • matlab-deploy-ai-model — MATLAB과 Simulink 워크플로 모두에서 LiteRT™ 코드 생성(loadLiteRTModel) 지원이 추가되었습니다.
  • matlab-deploy-embedded-code — ARM® Cortex-A SIMD/CRL 가이드가 보강되었고, Simulink Coder 속성에 대한 참조가 추가되었습니다.
  • matlab-design-radar-waveform — 스프레드 스펙트럼 및 위상 코딩 파형(M-시퀀스, PN 코드, 이중 기능 레이더-통신 파형) 지원과 스펙트럴 노칭 참조 자료가 추가되었습니다.
  • matlab-generate-code — 호스트-타겟 SIMD 구성(InstructionSetExtensions, SIMDAcceleration, OptimizeReductions)과 lib/dll/exe 및 MEX 타겟용 OpenMP 가이드가 추가되었습니다.
  • matlab-install-products — PowerShell 기반 워크플로에 대한 파일 생성 프로토콜을 강화하여 Windows® 에이전트 지원이 개선되었습니다.

호환성 관련 주요 변경 사항

22개 스킬 이름 변경 — 툴킷 내 다른 스킬과의 명명 일관성 및 명확성을 높이기 위해 이름이 변경되었습니다. 이전 스킬을 설치한 경우 설치 프로그램을 다시 실행하여 새 버전으로 전환해야 하며, 에이전트 지침 등 이전 스킬 이름을 수동으로 참조하고 있는 부분도 함께 업데이트해야 합니다.
