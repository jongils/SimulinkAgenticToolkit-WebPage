Simulink Agentic Toolkit News

빌드 날짜: 2026-08-13

이번 빌드의 변경사항

matlab-mcp-server, simulink-agentic-toolkit, matlab-agentic-toolkit 세 저장소의 최신 릴리스 변경 내용을 정리했습니다.

matlab-mcp-server v0.11.3

  • 보안 강화 — restoredefaultpath 호출 보호: restoredefaultpath 호출 주변에 보호 로직이 추가되어, 의도치 않게 MATLAB 경로 설정이 초기화되는 상황을 방지합니다.
  • run_matlab_file 툴의 파일 경로 검증 추가: 이제 run_matlab_file 툴이 파일을 실행하기 전에 MATLAB 파일 경로의 유효성을 먼저 검사합니다. 잘못되었거나 존재하지 않는 경로로 인한 예기치 않은 동작을 줄여줍니다.
  • 의존성 업데이트로 CVE 해소: 알려진 보안 취약점(CVE)을 해결하기 위해 서버가 사용하는 의존 라이브러리들이 최신 버전으로 갱신되었습니다.

simulink-agentic-toolkit 2026.08.12

새로운 기능

  • simulink-use-c-function-block 스킬 신규 추가: 에이전트가 Simulink C Function 블록을 구성하여 사용자 정의 C/C++ 코드를 모델에 통합하도록 안내하는 스킬입니다. 기존에는 레거시 S-Function 패턴으로 대체되던 작업을 이제 더 현대적인 방식으로 처리할 수 있습니다.

스킬 및 도구 개선

  • simulating-simulink-models 스킬의 트리거 범위 정교화: 파라미터 오버라이드, 배치 실행, 사용자 정의 입력 등 구체적인 시뮬레이션 설정을 요청할 때만 활성화되도록 개선되어, 다른 스킬이 처리해야 할 일반적인 모델링 요청에는 더 이상 관여하지 않습니다.
  • author-modeladvisor-checks 스킬 기능 확장: 포맷 템플릿 검사(format-template checks), 구성 파라미터 검사(configuration-parameter checks), 컴파일 후 컨텍스트 검사(post-compile context checks) 등 더 많은 Model Advisor 검사 유형 작성을 지원하며, 레거시 검사를 최신 상세 스타일로 변환하는 기능도 추가되었습니다.

버그 수정

  • model_edit의 Sqrt/Product 블록 오류 수정: Sqrt 블록을 요청하면 더 이상 역제곱근(1/sqrt(x)) 블록이 생성되지 않고, Product 블록을 요청하면 더 이상 나누기(divide) 블록이 생성되지 않습니다. (이슈 #58, #57)
  • Integrator, Second-Order 블록 이름 매칭 오류 수정: Simulink Library Browser 이름으로 Integrator, Second-Order 블록을 추가하면 이제 표준 Integrator가 아닌 실제 2차 적분기(Second-Order Integrator) 블록이 생성됩니다. (이슈 #55)
  • setupAgenticToolkit("update") 다운로드 실패 수정: 다운로드 타임아웃이 짧아서 느린 네트워크 환경에서 업데이트가 실패하던 문제가 해결되었습니다. (이슈 #59)
  • 일반 모델이 섞인 디렉터리의 커스텀 라이브러리 등록 오류 수정: 라이브러리가 아닌 일반 모델 파일이 함께 있는 디렉터리를 등록할 때 더 이상 실패하지 않으며, 라이브러리가 아닌 파일은 자동으로 건너뜁니다.
  • model_edit에서 DateTime 블록 계열 사용 가능: 에이전트가 모델을 구성할 때 이제 Simulink DateTime 블록 계열을 추가할 수 있습니다.
  • Simscape 물리 포트 레이블링 일관성 개선: 동일한 포트에 여러 연결이 있는 Simscape 서브시스템에서 모델 개요와 읽기 결과의 포트 레이블이 일관되게 표시됩니다.
  • 자동 레이아웃 안정성 개선: 서로 다른 다이어그램에 대한 연속적인 레이아웃 요청이 더 이상 오류를 일으키지 않으며, 결과를 가져올 수 없을 때 멈추지 않고 빠르게 실패 처리됩니다.

matlab-agentic-toolkit 2026.08.13

기존 스킬 그룹에 신규 스킬 추가

  • 이미지 처리 및 컴퓨터 비전: 초분광(hyperspectral) 및 다분광(multispectral) 이미지를 읽고, 처리, 분석, 라벨링, 분류하기 위한 matlab-analyze-spectral-images 스킬이 새로 추가되었습니다.

스킬 개선

  • matlab-analyze-data — 함수 핸들 셀렉터 및 in-place 변환을 다루는 convertvars 관련 문서가 확장되었습니다.
  • matlab-build-industrial-hmi — App Designer 직렬화(.mlapp 출력)를 위한 matlab-build-app 연계 처리와, 이를 사용할 수 없을 때의 프로그래밍 방식 대체 경로가 추가되었습니다.
  • matlab-deploy-ai-model — MATLAB 및 Simulink 워크플로우 모두에 LiteRT™ 코드 생성 지원(loadLiteRTModel)이 추가되었습니다.
  • matlab-deploy-embedded-code — ARM® Cortex-A SIMD/CRL 가이드가 개선되었고, Simulink Coder 속성에 대한 참조가 추가되었습니다.
  • matlab-design-radar-waveform — 스프레드 스펙트럼 및 위상 코드 파형(M-시퀀스, PN 코드, 이중 기능 레이더-통신 파형) 지원과 스펙트럼 노칭(notching) 참조가 추가되었습니다.
  • matlab-generate-code — 호스트-타깃 SIMD 구성(InstructionSetExtensions, SIMDAcceleration, OptimizeReductions)과 lib/dll/exe 및 MEX 타깃용 OpenMP 가이드가 추가되었습니다.
  • matlab-install-products — PowerShell 기반 워크플로우에 대해 더 엄격한 파일 생성 규칙을 적용하여 Windows® 에이전트 지원이 강화되었습니다.

호환성 관련 주요 변경사항

  • 22개 스킬 이름 변경: 툴킷 내 다른 스킬과의 명명 일관성 및 명확성을 위해 22개 스킬의 이름이 변경되었습니다. 이전 스킬을 설치했다면 설치 프로그램을 다시 실행하여 새 버전으로 전환해야 하며, 에이전트 지침 등에서 이전 스킬 이름을 수동으로 참조하고 있다면 함께 갱신해야 합니다.
  • 3개 스킬로 통합: 여러 개별 스킬이 3개의 통합 스킬(matlab-package-toolbox, matlab-connect-databricks, matlab-use-database)로 대체되었습니다. 개별 스킬을 설치했다면 설치 프로그램을 다시 실행하여 통합 버전으로 전환해야 합니다.
