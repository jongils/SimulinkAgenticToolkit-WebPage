simulink-agentic-toolkit 2026.08.19

신규 기능

  • simulink-control-motors 스킬 추가 — 에이전트가 Motor Control Blockset 모델을 구축하도록 안내하는 새 스킬입니다. 검증된 아키텍처 패턴과 16가지 모터 구동 토폴로지에 대한 미리 구성된 설정을 제공합니다.

스킬/도구 개선

  • checking-model-compliance 스킬 확장 — 기존 컴플라이언스 표준에 더해 이제 Simulink Code Inspector(SLCI) 기준의 모델 검사도 지원합니다.
  • 시뮬레이션 오류 진단 개선 — 시뮬레이션이 실패할 경우, model_read_diagnostics가 이전에는 일반적인 메시지 뒤에 가려져 있던 근본 원인(구체적인 블록 경로와 오류 상세 정보)을 보고하도록 개선되었습니다.

버그 수정

  • 작은 모델이 빈 모델로 오인되는 문제 — 에이전트가 단순하고 작은 모델을 설명할 때 더 이상 이를 빈 모델로 잘못 해석하지 않습니다.
  • 마스크된 Simscape Power Systems 포트 재배선 시 잘못된 엔드포인트 연결 문제 — model_edit이 마스크된 Specialized Power Systems 블록을 재배선할 때 의도한 물리 포트에 올바르게 연결합니다 (이슈 #63).
  • 연결 실패 시 기존 연결이 조용히 삭제되는 문제 — 이미 연결된 입력 포트에 연결을 시도하다 실패하는 경우, model_edit이 기존 연결을 제거하지 않고 그대로 보존합니다 (이슈 #62).
  • 이름으로 추가한 Trigonometric Function 블록이 근사 사인값을 계산하는 문제 — Simulink Library Browser의 이름으로 Trigonometric Function 블록을 추가할 경우, 이제 CORDIC 근사값이 아닌 정확한 사인 함수가 생성되어 의도치 않은 출력 차이를 방지합니다 (이슈 #61).

matlab-agentic-toolkit 2026.08.13

새로운 스킬

  • 이미지 처리 및 컴퓨터 비전 — matlab-analyze-spectral-images: 초분광(hyperspectral) 및 다중분광(multispectral) 이미지를 읽고, 처리하고, 분석·라벨링·분류하기 위한 스킬이 추가되었습니다.

기존 스킬 개선

  • matlab-analyze-data — 함수 핸들 셀렉터와 in-place 변환을 다루는 convertvars 문서가 확장되었습니다.
  • matlab-build-industrial-hmi — .mlapp 출력을 위한 App Designer 직렬화(serialization) 작업을 matlab-build-app으로 넘기는 핸드오프와, 이를 사용할 수 없을 때의 프로그래매틱 대체 경로가 추가되었습니다.
  • matlab-deploy-ai-model — MATLAB과 Simulink 워크플로 모두에 LiteRT™ 코드 생성 지원(loadLiteRTModel)이 추가되었습니다.
  • matlab-deploy-embedded-code — ARM® Cortex-A SIMD/CRL 가이드가 보강되고 Simulink Coder 속성에 대한 참고 자료가 추가되었습니다.
  • matlab-design-radar-waveform — 스프레드 스펙트럼 및 위상 부호화 파형(M-시퀀스, PN 코드, 이중 기능 레이더-통신 파형) 지원과 스펙트럴 노칭(spectral notching) 참고 자료가 추가되었습니다.
  • matlab-generate-code — 호스트-타겟 SIMD 구성(InstructionSetExtensions, SIMDAcceleration, OptimizeReductions)과 lib/dll/exe 및 MEX 타겟용 OpenMP 가이드가 추가되었습니다.
  • matlab-install-products — PowerShell 기반 워크플로에 대해 더 엄격한 파일 생성 프로토콜로 Windows® 에이전트 지원이 강화되었습니다.

호환성 관련 주의사항

  • 22개 스킬 이름 변경 — 다른 툴킷 스킬과의 명확성 및 일관성을 위해 이름이 변경되었습니다. 이전 스킬을 설치한 경우 설치 프로그램을 다시 실행하여 새 버전으로 전환해야 하며, 에이전트 지침 등에서 이전 스킬 이름을 수동으로 참조하고 있다면 함께 업데이트해야 합니다. 주요 변경 예: matlab-debugging → matlab-debug-code, matlab-testing → matlab-write-test, matlab-theming → matlab-apply-theme, matlab-sharing → matlab-share-content, matlab-ocr → matlab-recognize-text 등 총 22개 항목이 변경되었습니다.
  • 3개 스킬 통합 — 여러 개별 스킬이 통합 스킬로 대체되었습니다: 툴박스 패키징 관련 9개 스킬 (matlab-analyze-dependencies, matlab-assess-toolbox, matlab-build-toolbox 등)이 matlab-package-toolbox로, Databricks 연결 관련 2개 스킬이 matlab-connect-databricks로, 데이터베이스 관련 3개 스킬이 matlab-use-database로 통합되었습니다. 개별 스킬을 설치한 경우 설치 프로그램을 다시 실행하여 통합 버전으로 전환해야 합니다.
