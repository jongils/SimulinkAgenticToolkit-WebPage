Simulink Agentic Toolkit News

빌드 날짜 2026-08-13

MATLAB / Simulink Agentic Toolkit 생태계의 세 저장소에서 최근 발표된 변경사항을 한눈에 확인하세요.

이번 업데이트의 변경사항

matlab-mcp-server v0.11.3

개선 사항

  • restoredefaultpath 호출 시 발생할 수 있는 문제를 막기 위한 보호 로직이 추가되었습니다.
  • run_matlab_file 도구가 MATLAB 파일을 실행하기 전에 파일 경로를 먼저 검증하도록 개선되어, 잘못된 경로로 인한 오류를 사전에 방지합니다.
  • 알려진 CVE(보안 취약점)를 해소하기 위해 내부 종속 패키지들이 업데이트되었습니다.

simulink-agentic-toolkit 2026.08.12

새로운 기능

  • simulink-use-c-function-block 스킬이 새로 추가되었습니다. 레거시 S-Function 패턴 대신, 사용자 정의 C/C++ 코드를 Simulink C Function 블록에 통합하도록 에이전트를 안내합니다.

스킬 및 도구 개선

  • simulating-simulink-models 스킬이 더 정교해졌습니다. 이제 파라미터 오버라이드, 배치 실행, 사용자 정의 입력 등 구체적인 시뮬레이션 설정을 요청할 때만 활성화되어, 다른 스킬이 더 적합한 일반적인 모델링 요청에는 더 이상 개입하지 않습니다.
  • author-modeladvisor-checks 스킬이 더 다양한 Model Advisor 검사 유형(포맷 템플릿 검사, 구성 파라미터 검사, 컴파일 후 컨텍스트 검사)을 지원하며, 레거시 검사를 최신 상세 스타일로 변환하는 기능도 추가되었습니다.

버그 수정

  • model_edit이 Sqrt와 Product 블록 요청 시 잘못된 블록을 생성하던 문제가 수정되었습니다. 이제 Sqrt 요청 시 역제곱근(1/sqrt(x)) 블록이 아닌 올바른 제곱근 블록이, Product 요청 시 나눗셈이 아닌 올바른 곱셈 블록이 생성됩니다. (이슈 #58, #57)
  • Simulink Library Browser 이름으로 Integrator, Second-Order 블록을 추가할 때 일반 Integrator 블록이 생성되던 문제가 수정되어, 이제 올바르게 2차 적분기 블록이 생성됩니다. (#55)
  • 네트워크 속도가 느린 환경에서 다운로드 타임아웃이 너무 짧아 setupAgenticToolkit("update")가 실패하던 문제가 해결되었습니다. (#59)
  • 일반 모델 파일이 함께 있는 디렉터리를 사용자 정의 라이브러리로 등록할 때 실패하던 문제가 수정되었습니다. 이제 라이브러리가 아닌 파일은 자동으로 건너뜁니다.
  • model_edit에서 Simulink DateTime 블록 계열을 추가할 수 있게 되었습니다.
  • Simscape 서브시스템에서 동일 포트에 여러 연결이 있는 경우, 모델 개요 화면과 읽기 결과의 포트 라벨 표기가 일관되게 개선되었습니다.
  • 자동 레이아웃 안정성이 향상되었습니다. 서로 다른 다이어그램에 대해 레이아웃 요청을 연속으로 수행해도 더 이상 오류가 발생하지 않으며, 결과를 얻을 수 없는 경우 무한 대기 대신 빠르게 실패합니다.

기존 스킬 그룹에 추가된 신규 스킬

  • 영상 처리 및 컴퓨터 비전 — matlab-analyze-spectral-images 스킬이 추가되어, 초분광(hyperspectral) 및 다중분광(multispectral) 영상을 읽고 처리·분석·라벨링·분류하는 작업을 지원합니다.

개선된 스킬

  • matlab-analyze-data — 함수 핸들 기반 선택자와 인플레이스 변환을 다루는 convertvars 관련 문서가 확장되었습니다.
  • matlab-build-industrial-hmi — .mlapp 출력이 필요한 App Designer 직렬화를 위해 matlab-build-app으로의 연계 처리가 추가되었고, 이를 사용할 수 없는 경우를 위한 프로그래밍 방식 대체 경로도 추가되었습니다.
  • matlab-deploy-ai-model — MATLAB과 Simulink 워크플로 모두에서 LiteRT™ 코드 생성 지원(loadLiteRTModel)이 추가되었습니다.
  • matlab-deploy-embedded-code — ARM® Cortex-A SIMD/CRL 관련 가이드가 보강되었고, Simulink Coder 속성에 대한 참고 자료가 추가되었습니다.
  • matlab-design-radar-waveform — 스프레드 스펙트럼 및 위상 부호화 파형(M-시퀀스, PN 코드, 듀얼 기능 레이더-통신 파형) 지원과 스펙트럼 노칭 관련 참고 자료가 추가되었습니다.
  • matlab-generate-code — 호스트-타겟 SIMD 구성(InstructionSetExtensions, SIMDAcceleration, OptimizeReductions) 및 lib/dll/exe와 MEX 타겟을 위한 OpenMP 가이드가 추가되었습니다.
  • matlab-install-products — PowerShell 기반 워크플로에 대해 더 엄격한 파일 생성 규칙을 적용하여 Windows® 환경에서의 에이전트 지원이 강화되었습니다.

호환성 관련 참고 사항

명확성과 다른 스킬과의 명명 일관성을 위해 22개의 스킬 이름이 변경되었습니다. 이전 스킬을 설치한 경우, 새 버전으로 전환하려면 설치 프로그램을 다시 실행해야 합니다. 에이전트 지침 등에서 이전 스킬 이름을 수동으로 참조하고 있다면 그 부분도 함께 업데이트해야 합니다.
