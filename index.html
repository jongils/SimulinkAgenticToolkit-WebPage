MATLAB & Simulink Agentic Toolkit 최신 소식

2026-08-14 빌드

이번 빌드 한눈에 보기

  • Simulink 신규 스킬 — C Function 블록 구성을 안내하는 simulink-use-c-function-block 스킬이 추가되어 커스텀 C/C++ 코드 통합이 쉬워졌습니다.
  • Simulink 버그 다수 수정 — Sqrt/Product 블록 오생성, Integrator, Second-Order 이름 해석 오류, 업데이트 다운로드 타임아웃 등 실사용에 영향을 주던 문제들이 해결되었습니다.
  • MATLAB 신규 스킬 — 하이퍼스펙트럴/멀티스펙트럴 이미지 분석을 위한 matlab-analyze-spectral-images 스킬이 추가되었습니다.
  • MATLAB 스킬 대규모 정리 — 22종의 스킬 이름이 더 명확하게 변경되고, 9종의 개별 스킬이 3종의 통합 스킬로 재구성되었습니다. 재설치가 필요합니다.
  • MCP 서버 안정성 수정 — Windows에서 DotNetFacade 이름-값 인자를 거부하던 문제가 해결되었습니다.

새로운 기능

  • simulink-use-c-function-block 스킬 추가 — 커스텀 C/C++ 코드를 Simulink 모델에 통합할 때, 오래된 S-Function 방식 대신 C Function 블록을 구성하도록 에이전트를 안내하는 새로운 스킬입니다.

스킬/도구 개선

  • simulating-simulink-models 스킬 범위 조정 — 이제 파라미터 재정의, 배치 실행, 커스텀 입력 등 구체적인 시뮬레이션 설정을 요청할 때만 활성화되며, 다른 스킬이 더 적합한 일반적인 모델링 요청에는 더 이상 끼어들지 않습니다.
  • author-modeladvisor-checks 스킬 기능 확장 — 포맷 템플릿 검사, 설정 파라미터 검사, 컴파일 후 컨텍스트 검사 등 더 많은 Model Advisor 체크 유형 작성을 지원하고, 기존 레거시 체크를 새로운 상세 스타일로 변환하는 기능도 추가되었습니다.

버그 수정

  • model_edit 이 Sqrt, Product 블록을 잘못 생성하던 문제 수정 — Sqrt 블록 요청 시 더 이상 역제곱근(1/sqrt(x)) 블록이 생성되지 않고, Product 요청 시 더 이상 나눗셈 블록이 생성되지 않습니다. (#58, #57)
  • Integrator, Second-Order 블록 이름 해석 오류 수정 — Simulink 라이브러리 브라우저의 이름으로 이 블록을 추가하면 이제 일반 Integrator가 아니라 실제 2차 적분기 블록이 생성됩니다. (#55)
  • setupAgenticToolkit("update") 다운로드 실패 수정 — 다운로드 타임아웃이 너무 짧게 설정되어 있던 문제로 인해 느린 네트워크 환경에서 업데이트가 실패하던 현상을 해결했습니다. (#59)
  • 일반 모델이 섞여 있는 디렉터리의 커스텀 라이브러리 등록 오류 수정 — 라이브러리가 아닌 일반 모델 파일이 포함된 디렉터리를 등록해도 더 이상 실패하지 않고, 라이브러리가 아닌 파일은 건너뜁니다.
  • model_edit 에서 DateTime 블록 계열을 사용할 수 없던 문제를 수정하여, 이제 에이전트가 모델 작성 시 Simulink DateTime 블록군을 추가할 수 있습니다.
  • Simscape 물리 포트 라벨링 수정 — 동일 포트에 여러 연결이 있는 Simscape 서브시스템에서 모델 개요와 읽기 결과의 포트 라벨이 이제 일관되게 표시됩니다.
  • 자동 레이아웃 안정성 개선 — 서로 다른 다이어그램에 대한 연속적인 레이아웃 요청이 더 이상 오류를 일으키지 않으며, 결과를 얻을 수 없을 때 멈추지 않고 빠르게 실패하도록 개선되었습니다.

새로운 스킬

  • 이미지 처리 및 컴퓨터 비전 — 하이퍼스펙트럴/멀티스펙트럴 이미지를 읽고, 처리하고, 분석하고, 라벨링하고, 분류하기 위한 matlab-analyze-spectral-images 스킬이 추가되었습니다.

기존 스킬 개선

  • matlab-analyze-data — 함수 핸들 선택자 및 in-place 변환을 다루는 convertvars 관련 문서가 보강되었습니다.
  • matlab-build-industrial-hmi — .mlapp 출력으로 App Designer 직렬화를 수행하기 위해 matlab-build-app 으로의 연계 기능과, 이를 사용할 수 없을 때의 프로그래밍 방식 대체 경로가 추가되었습니다.
  • matlab-deploy-ai-model — MATLAB과 Simulink 워크플로 모두에서 loadLiteRTModel 을 통한 LiteRT™ 코드 생성 지원이 추가되었습니다.
  • matlab-deploy-embedded-code — ARM® Cortex-A SIMD/CRL 가이드가 정교해지고, Simulink Coder 속성에 대한 참조가 추가되었습니다.
  • matlab-design-radar-waveform — 스프레드 스펙트럼 및 위상 코딩 파형(M-시퀀스, PN 코드, 듀얼 기능 레이더-통신 파형) 지원과 스펙트럴 노칭 참조가 추가되었습니다.
  • matlab-generate-code — 호스트-타깃 SIMD 설정(InstructionSetExtensions, SIMDAcceleration, OptimizeReductions)과 lib/dll/exe 및 MEX 타깃을 위한 OpenMP 가이드가 추가되었습니다.
  • matlab-install-products — PowerShell 기반 워크플로에 대한 파일 생성 규칙을 강화하여 Windows® 에이전트 지원이 개선되었습니다.

호환성 관련 주의사항

  • 스킬 22종 이름 변경 — 명확성과 다른 스킬과의 일관성을 위해 이름이 변경되었습니다. 이전 버전의 스킬을 설치한 경우 설치 프로그램을 다시 실행하여 새 버전으로 전환해야 하며, 에이전트 지침 등에서 이전 스킬 이름을 수동으로 참조하고 있다면 이것도 함께 업데이트해야 합니다. 주요 변경 예시: matlab-debugging → matlab-debug-code, matlab-read-doc → matlab-read-documentation, matlab-testing → matlab-write-test, matlab-theming → matlab-apply-theme 외 18종 (전체 목록은 저장소의 릴리스 노트를 참고하세요).
  • 스킬 9종 → 3종으로 통합 — matlab-analyze-dependencies, matlab-assess-toolbox, matlab-build-toolbox, matlab-create-buildfile, matlab-create-project, matlab-define-toolbox-api, matlab-document-toolbox, matlab-exclude-files, matlab-publish-toolbox 는 matlab-package-toolbox 로 통합되었습니다. matlab-connect-databricks-jdbc, matlab-connect-databricks-spark 는 matlab-connect-databricks 로, matlab-map-database-objects, matlab-read-database, matlab-write-database 는 matlab-use-database 로 각각 통합되었습니다. 개별 스킬을 설치했던 경우 설치 프로그램을 다시 실행하여 통합된 버전으로 전환하세요.
