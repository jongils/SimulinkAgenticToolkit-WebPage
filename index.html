matlab-mcp-server v0.11.4

이번 릴리스는 버그 수정 1건만 포함된 소규모 패치입니다.

  • Windows에서 DotNetFacade 이름-값 인자 오류 수정 — CoreDotNetAccessControl이 Windows 환경에서 DotNetFacade 이름-값(name-value) 인자를 거부하던 문제(#113)가 해결되었습니다. Windows에서 MATLAB MCP Server를 사용하는 환경이라면 이번 업데이트를 적용하는 것이 좋습니다.

simulink-agentic-toolkit 2026.08.12

새로운 기능

  • simulink-use-c-function-block 스킬 신규 추가 — Simulink C Function 블록을 구성해 사용자 정의 C/C++ 코드를 모델에 통합하는 작업을 에이전트가 안내합니다. 기존에는 레거시 S-Function 패턴으로 우회하던 작업을 이제 정식 스킬로 처리할 수 있습니다.

스킬 및 도구 개선

  • simulating-simulink-models 스킬 트리거 범위 정교화 — 이제 파라미터 오버라이드, 배치 실행, 커스텀 입력 등 구체적인 시뮬레이션 설정 요청이 있을 때만 활성화됩니다. 일반적인 모델링 요청에서는 더 이상 불필요하게 트리거되지 않고, 그 경우에 더 적합한 다른 스킬에 맡깁니다.
  • author-modeladvisor-checks 스킬 기능 확장 — 포맷 템플릿 체크, 구성 파라미터 체크, 컴파일 후(post-compile) 컨텍스트 체크 등 더 많은 Model Advisor 체크 유형 작성을 지원하며, 레거시 체크를 최신 상세 스타일로 변환하는 기능도 추가되었습니다.

버그 수정

  • model_edit의 Sqrt/Product 블록 생성 오류 수정 — Sqrt 블록을 요청하면 더 이상 역제곱근(1/sqrt(x)) 블록이 생성되지 않고, Product 블록을 요청하면 더 이상 나눗셈(divide) 블록이 생성되지 않습니다. (#58, #57)
  • Integrator, Second-Order 블록 이름 해석 오류 수정 — Simulink Library Browser 이름으로 Integrator, Second-Order 블록을 추가하면 이제 일반 Integrator가 아닌 실제 Second-Order Integrator 블록이 생성됩니다. (#55)
  • setupAgenticToolkit("update") 다운로드 타임아웃 수정 — 다운로드 타임아웃이 짧게 설정되어 있어 느린 네트워크 환경에서 업데이트가 실패하던 문제가 해결되었습니다. (#59)
  • 일반 모델이 섞인 디렉터리의 커스텀 라이브러리 등록 오류 수정 — 라이브러리가 아닌 일반 모델 파일이 함께 있는 디렉터리를 등록해도 더 이상 실패하지 않으며, 라이브러리가 아닌 파일은 자동으로 건너뜁니다.
  • model_edit에서 DateTime 블록군 사용 가능 — 에이전트가 모델을 구성할 때 Simulink DateTime 블록 계열을 추가할 수 있게 되었습니다.
  • Simscape 물리 포트 라벨링 일관성 개선 — 동일 포트에 여러 연결이 있는 Simscape 서브시스템에서 모델 개요와 읽기 출력 간 포트 라벨이 일관되게 표시됩니다.
  • 자동 레이아웃 안정성 개선 — 서로 다른 다이어그램에 대해 연속으로 레이아웃을 요청해도 더 이상 오류가 발생하지 않으며, 결과를 얻을 수 없을 때 멈추지 않고 빠르게 실패 처리됩니다.

matlab-agentic-toolkit 2026.08.13

기존 스킬 그룹에 추가된 새 스킬

  • 이미지 처리 및 컴퓨터 비전 — matlab-analyze-spectral-images 신규 추가. 초분광(hyperspectral) 및 다분광(multispectral) 이미지를 읽고, 처리하고, 분석하고, 라벨링하고, 분류하는 작업을 지원합니다.

스킬 개선

  • matlab-analyze-data — 함수 핸들 선택자(function-handle selector)와 in-place 변환을 다루는 convertvars 관련 문서가 확장되었습니다.
  • matlab-build-industrial-hmi — .mlapp 출력용 App Designer 직렬화를 위해 matlab-build-app으로의 핸드오프가 추가되었고, App Designer를 사용할 수 없을 때의 프로그래밍 방식 대체 경로도 추가되었습니다.
  • matlab-deploy-ai-model — MATLAB 및 Simulink 워크플로 모두에서 LiteRT™ 코드 생성(loadLiteRTModel) 지원이 추가되었습니다.
  • matlab-deploy-embedded-code — ARM® Cortex-A SIMD/CRL 관련 가이드가 정교화되었고, Simulink Coder 속성에 대한 레퍼런스가 추가되었습니다.
  • matlab-design-radar-waveform — 스프레드 스펙트럼 및 위상 코드 파형(M-시퀀스, PN 코드, 듀얼 기능 레이더-통신 파형) 지원과 스펙트럼 노칭(notching) 레퍼런스가 추가되었습니다.
  • matlab-generate-code — 호스트-타깃 SIMD 구성(InstructionSetExtensions, SIMDAcceleration, OptimizeReductions)과 lib/dll/exe 및 MEX 타깃을 위한 OpenMP 가이드가 추가되었습니다.
  • matlab-install-products — PowerShell 기반 워크플로에서 파일 생성 규칙을 강화하여 Windows 에이전트 지원이 개선되었습니다.
